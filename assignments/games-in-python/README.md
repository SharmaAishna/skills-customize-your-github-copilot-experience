# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build the classic word-guessing game using Python strings, loops, and user input so you can practice essential programming concepts in a fun, interactive project.

## 📝 Tasks

### 🛠️ Create the Guessing Game

#### Description
Create a Hangman game where players guess letters to reveal a hidden word before running out of attempts.

#### Requirements
Completed program should:

- Randomly select a word from a predefined list
- Accept letter guesses from the player
- Show the current progress using blanks and correctly guessed letters
- Track how many incorrect guesses remain
- End the game when the player wins or runs out of attempts
- Display a clear win or lose message at the end

### 🛠️ Improve the Game Experience

#### Description
Add a few polished game behaviors so the player can clearly follow the game state during each round.

#### Requirements
Completed program should:

- Display the guessed letters so the player can track progress
- Prevent repeated guesses from being counted twice
- Show the hidden word or final result after the game ends
- Keep the game loop simple and easy to follow
